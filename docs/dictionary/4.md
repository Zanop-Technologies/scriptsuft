# Entry 4: Math and Expressions

Scriptsuft supports direct arithmetic expressions inside code examples. The runtime evaluates simple numeric expressions using normal arithmetic rules.

## Example

```text
math class {
    problem: [2+2]
}
```

Meaning:
- Expressions inside `[...]` are evaluated as arithmetic expressions.
- You can use `+`, `-`, `*`, `/` and parentheses for grouping.

## Examples

```text
math class { problem: [1 + 2 * (3 + 4)] }
math class { problem: [10 / 2] }
```

The runtime will evaluate the expression and (in examples) emit the resulting value.

## Notes

- No `!indef math` is required — math is built into expression evaluation.
- Numeric literals are integers or floats (e.g. `42`, `3.14`).
- Expressions may appear inside other constructs where the docs show bracket notation.
- For complex math, combine expressions with variables: `x = 2 + 3` then use `math class { problem: [x * 5] }`.
