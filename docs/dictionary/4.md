# Entry 4: Math and Expressions

Scriptsuft supports direct arithmetic expressions inside code examples.

## Example

```text
math class {
    problem: [2+2]
}
```

This example implies that arithmetic expressions are written in bracket notation and can be evaluated directly.

## Common operations

- addition: `2 + 2`
- subtraction: `5 - 3`
- multiplication: `4 * 2`
- division: `8 / 2`

## Notes

The project documentation describes math as a built-in capability without requiring a dedicated `!indef math` import, so expressions are expected to be evaluable as part of the language runtime.
