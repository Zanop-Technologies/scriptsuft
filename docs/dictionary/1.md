# Entry 1: Core Language Keywords

This page documents the primitive keywords and runtime concepts used throughout Scriptsuft examples.

## `!indef`

Import a library or namespace.

```text
!indef system
!indef func(print)
!indef is print
!indef is console
```

Meaning:
- `!indef` loads a library or module.
- `!indef func(name)` declares a function name.
- `!indef is submodule` imports a submodule or settings namespace.

## `speak()`

Print a string, expression, or variable.

```text
speak("Hello World")
speak var(name)
```

Notes:
- `speak("text")` prints a literal string.
- `speak var(name)` prints the value stored in the variable `name`.
- In the runtime implementation, this is handled as a standard output expression.

## `compile()`

Finalize or execute the current script.

```text
compile()
```

This is used in the examples as the final action to mark script completion.

## `def(static)`

Create a static variable.

```text
def(static) var{"name"} res{"John"}
def(static) var{"age"} intres{18}
```

Meaning:
- `def(static)` declares a fixed value.
- `var{"name"}` names the variable.
- `res{"value"}` stores a string.
- `intres{18}` stores an integer value.

## `var(...)`

Reference a variable value by name.

```text
speak var(name)
```

This reads the stored variable `name` and passes it to `speak()`.

## Comments

Scriptsuft examples allow several comment styles:

```text
# one-line comment
// one-line comment
/* multi-line comment */
<!-- multi-line comment -->
```
