# Entry 2: Control Flow

These keywords manage logic and repetition.

## `if`

Run a block when a condition is true.

```text
if age is 18:
    speak("You are allowed")
```

The runtime interprets the condition with ScriptSuft-style comparisons such as:
- `is`
- `is not`
- `(=)` (treated as equality)
- `(+)` (treated as inequality in docs)

Notes:
- Conditions accept friendly words like `is` and `is not` which the runtime translates to `==` / `!=`.
- Use `and`, `or`, and `not` for logical combinations.

## `else`

Run a fallback block when the condition is false.

```text
if age is 18:
    speak("You are allowed")
else:
    speak("You are not allowed")
```

## `while` and `loop-limit`

Repeat a block while the condition remains true. Prefer using `loop-limit(...)` before a `while` to avoid infinite loops.

```text
loop-limit(5)
while age is 18:
    speak("Looping")
```

Behavior:
- `loop-limit(n)` sets a maximum number of iterations the runtime will perform for `while` blocks. If absent, the runtime uses a large safety cap.
- Blocks are defined by indentation (like Python) in examples — the runtime treats an indented block as the loop body.

## `switch` and `case`

Select a branch based on a value.

```text
switch class("Day1") [
    case(=) create-msg("Monday")
]
```

Behavior:
- `switch expr [ ... ]` evaluates `expr` and compares it to each `case(...)` value.
- `case(op)` in the docs is a compact shorthand — the runtime matches `case` values by string equality against the evaluated expression.
- Case statements may directly call actions like `create-msg(...)` or `speak(...)`.
