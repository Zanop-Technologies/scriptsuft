# Entry 3: Variables and Data

Scriptsuft distinguishes between static and dynamic values.

## Static variables

```text
def(static) var{"name"} res{"John"}
```

Static variables keep a fixed value after declaration.

## Dynamic variables

The docs mention dynamic variables for input-driven data, although the runtime examples focus on static variables in the basics section.

```text
if (function=live) is !declared(=) {
    __live__ can change if user_input is recorded
}
```

Dynamic values can change as user input or runtime state updates.

## Literal types

Scriptsuft examples use:
- string literals: `"Hello"`
- integer literals: `18`
- boolean-like values: `on`, `off`, `true`, `false`
- `null`/`none` for empty values

## Comparison operators

The docs describe these comparison forms:

- `is` / `is not`
- `(=)`
- `(+)
- `and`, `or`, `not`

These are treated as boolean-style checks in the runtime interpreter.
